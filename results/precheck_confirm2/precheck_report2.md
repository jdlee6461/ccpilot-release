## A2. 재포착 상태의 정의

- **정책에 의존하지 않는다.** `evaluate._add_strata`: `hopkind = 0 if hop > 0; 1 if chain == 0; 2 otherwise`.

- 탐색 정책의 탐지·놓침 결과는 이 정의에 들어가지 않는다. 같은 자료와 T_max면 어느 방법을 쓰든 같은 hop이 재포착이다. hop만 만드는 사본이 원본 전이와 100% 같음은 2026-10-02 확인했다.

## A6. 비교군의 적합 방식과 코드 존재

- **static:** 보정 기간 점수의 split conformal 분위수. τ = 오름차순 ⌊α(n+1)⌋번째 점수이고, 모든 평가 hop에 같은 τ를 쓴다(`calibration.static_taus`).
- **Mondrian:** 시간대 × 첫 hop 여부 × 속도 4분위의 40칸마다 같은 split conformal 분위수를 쓴다. 보정 hop이 200 미만인 칸은 전역 τ를 쓴다(`mondrian_taus`, `mondrian_hour_hop_speed`, `min_group_n: 200`).
- **qr_groups:** log(점수)를 절편 + 6개 속성(시간대, hop 종류, 속도, 구역, 갈림길, 고립)의 기준 범주 지시변수에 대해 분위수 수준 α로 선형 분위수 회귀한다. 보정 기간 자료에서 최대 80,000개를 시드로 무작위 추출해 LP(HiGHS)로 풀고, τ = exp(x'β)를 쓴다(`multigroup.qr_group_taus`).

| 비교군 | 코드 | 설정 이름 | 동결 확인 설정에 있는가 |
|---|---|---|---|
| static | `calibration.static_taus` | `static` | 있음 |
| ACI(γ = 0.0005) | `calibration.aci_taus` | `aci_g0005` | 있음 |
| Mondrian | `calibration.mondrian_taus` | `mondrian_hour_hop_speed` | 있음 |

## A7. H3(사후 그룹 분위수 회귀)

- **정의:** `posthoc_group_oracle.py`의 기준 (b)다. qr_groups와 같은 설계(log 점수, 절편 + 6개 속성 기준 범주 지시변수, 분위수 수준 α)를 **평가 구간 자신의 점수**에 부분 추출 없이 적합하고(`max_n = n + 1`), 같은 hop에 적용한다.
- **설정값:** `qr_group_taus(..., max_n=len+1, seed=0, lp_method="highs-ipm")`.
  - HiGHS 내부점 + crossover로 같은 LP의 같은 최적해를 구한다. 기본 dual simplex는 약 265,000 hop에서 40분 안에 끝나지 않았다.
  - floor 1e-8, TAU_MIN 1e-12.
- **원고 M1과의 대응:** 원고 부록 표(`tab:group_oracle`)의 "(b) Hindsight group QR: the quantile regression of qr_groups fitted on the evaluation segment itself"와 같은 정의다.
  - 비용 기준도 같다. hop당 camera·s(`VisibilityModel.cost`, 같은 예측기를 재적합하고 저장된 점수·static 비용·사후 oracle 일치 세 가지를 점검)이고, 사후 oracle과 규칙 (a) 대비 비율로 보고한다.
  - 기준 (a)(그룹 최소 규칙)는 지시문의 H4와 같은 정의다.
- 주의: 지시문의 "블록별로 맞추고, 부트스트랩 반복마다 다시 맞춤"은 기존 구현(구간별 1회 적합)에 없는 부분이다. B에서 추가한다.

**H3의 목적함수·제약·풀이:**
- 목적함수: 블록 평가 hop 전부(부분 추출 없음)의 y_i = log(max(점수_i, 1e-8))에 대해 Σ_i [α·u_i⁺ + (1−α)·u_i⁻]를 최소화한다(분위수 수준 α = 1 − t의 점검 손실).
- 제약: x_i'β + u_i⁺ − u_i⁻ = y_i, u⁺, u⁻ ≥ 0, β 자유. x_i는 절편과 6개 속성(시간대 5, hop 종류 3, 속도 4, 구역 4, 갈림길 4, 고립 4)의 기준 범주 지시변수로 19개 계수다.
- 풀이: scipy `linprog(method="highs-ipm")`(HiGHS 내부점 + crossover). hop의 τ = max(exp(x_i'β), 1e-12)이고, 같은 hop에 적용한다.
- **그룹 회수율 ≥ t 보장: 정확한 LP 최적해라면 보장된다. 실제로는 근사다.**
  - 이론: 각 그룹의 지시는 설계 열(또는 그 선형결합)이다. 최적해에서 그 방향으로 계수를 움직이는 방향 도함수 조건이 성립하면, 그룹의 "y < 적합값" hop 수가 α·n_G 이하가 되어 회수율 ≥ t다(분위수 회귀의 부분기울기 조건).
  - 실측: 보류 기간 기존 결과(`group_oracle_groups.csv`, 목표 0.95)에서 25개 그룹 최소 회수율은 A 0.949975, B 0.949925였다. 목표보다 그룹당 최대 4.55 hop(B, 00–06시) 모자랐다.
  - 원인(해석): 적합값에 정확히 걸친 hop의 exp/log 반올림, LP 허용 오차, 점수 0(구조적 미탐)의 1e-8 하한 처리.
  - 보장으로 쓰려면 수치 여유(예: τ를 한 ulp 낮춤)나 사후 점검이 필요하다(제안, 미적용).

**이전 실험의 "시드 평균 비용 비율 1.27"의 기준:**
- **확인 불가**: 저장소 결과에서 "시드 평균 1.27"로 특정되는 값을 찾지 못했다.
  - 보류 기간 시드 0 ~ 4 평균은 mvp_log 1.155, qr_ogd 1.186이다(`seeds_prereg25/seeds_all.csv`).
  - 1.265 ~ 1.275 값은 장애 시나리오·민감도의 개별 실행 행에만 있다.
- 기록된 모든 비용 비율("× oracle", `cost_over_oracle*`)의 기준은 **사후 oracle**이다. 정의는 평가 구간 점수에서 `conformal_tau(score, α)`로 정한 단일 전역 임계값이다.
  - 이것은 H1(회수율 ≥ t인 가장 큰 단일 임계값)과 같은 종류다. 다만 유한 표본 보정(⌊α(n+1)⌋번째)이라 H1보다 순서 통계량 하나만큼 낮을 수 있다.
  - H2·H3·H4 대비 비율은 부록 표(그룹 최소 규칙 (a) = H4, 사후 그룹 QR (b) = H3)의 "× (a)" 열에만 있다.
  - 장애 분석에는 "같은 실행 oracle"과 "장애 없음 oracle" 두 종류가 있다.
