## 4. 재포착 시작 체인의 분해 (목표 0.95, 시드 평균 [95% 택시 군집 구간])

- 조건부 적중률 j: 체인 중 j번째 hop이 있고 hop 1..j−1이 모두 적중한 체인에서 hop j가 적중한 비율.
- 비용비 j: 재포착 시작 체인의 j번째 hop 전체(모든 방법에 같은 hop)의 hop당 평균 비용 ÷ static의 같은 값.
- 트랙 상태: j ≥ 2의 hop은 정의상 모두 later(hopkind 0)다. later 비중은 j = 2–5 모두 1.000–1.000이다.
- 재포착 시작 체인 비중: 합산 k = 1에서 4,390 / 208,988 = 2.1%.
